Out of alpha, skipped beta—we’re stable!

## What’s New?

- User-created profiles.
- Global app settings.
  - Open on system startup.
  - Close on join, which closes the application after joining a server.
- Server profile settings.
  - Profile deletion.
- More soon.

## Fixes and Improvements

- Fixed broken navigation logic.
- Improved connection logic. This is a breaking change and requires new profiles.
