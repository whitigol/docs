## New Features

- Added the ability to edit profiles.
  - User-created or explicitly editable profiles show all fields.
  - Default exported or explicitly non-editable profiles only allow editing the server name.
- Added the ability to export profiles.
  - Non-editable profiles cannot be exported, protecting private connection details.

## Bug Fixes and Improvements

- Improved internal application security.
- Removed an unused application protocol that may return in the future.
- Upgraded the route navigation dependency.
- Fixed routes broken by the navigation upgrade.
- Improved connection logic between the launcher and the FiveM client.
