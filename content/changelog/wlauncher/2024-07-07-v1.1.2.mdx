## New Features

- **Version Number Display** — Added a version number at the bottom of the application for easy reference.
- **Debug Mode** — Introduced a debug mode to assist with troubleshooting issues.
- **Enhanced Tooltips** — The Launch button on server profiles now includes a tooltip that provides additional information about the button’s state.

## Bug Fixes

- **Performance Improvements** — Resolved issues causing the launcher to slow down system performance.
- **FiveM Connection Fix** — Improved the connection method for FiveM users without FiveM NUI Debug enabled.
- **Update Method Changes** — Temporarily changed the update method to download the latest installer directly to avoid antivirus false positives.
