## Bug Fixes and Improvements

- Resolved an issue that required multiple attempts to connect to servers.
- Fixed a bug preventing required plugins from being recognized during profile creation.
- Corrected errors that occurred on the profile creation page.
- Improved overall performance for a smoother user experience.
- Patched an issue that prevented updates from downloading directly. Users are now directed to a website to download the update while a more streamlined update process is developed.

## New Features

- **App Themes** — Personalize your experience with a range of new color options, including light mode.
