## Bug Fixes

- **Profile Editing Works Again** — You can now update your profile without running into mysterious errors.
- **No More Accidental Clones** — A bug that let you create duplicate profiles has been squashed.
- **Plugins Won’t Get Confused** — Filling out plugin details in a random order won’t break things anymore.
- **Launching Without Issues** — The app now waits for FiveM to open before trying to connect.
- **Clear Error Messages** — If something goes wrong while making a profile, you’ll actually see an error message instead of nothing.
- **Removed the “Ghost Profile” Glitch** — Fixed a rare issue where a deleted profile would randomly reappear. Either a bug or a very committed profile that refused to be forgotten.

## Improvements

- **A Fresh Coat of Paint** — The “Big Daddy” theme got an update to be easier on the eyes.
- **No More Connection Tantrums** — The app now waits a little longer before giving up on connecting, preventing random failures. Never gonna give you up, never gonna… you get the point.
- **Faster Startups** — A splash screen now checks for updates and preloads everything, so the app is ready to go quicker.
- **Better Profile Management** — The UI handles long lists of profiles more smoothly.
- **Significantly Reduced Memory Usage** — The app is now better optimized, no longer using extra resources to think about its life choices.

## New Features

- **Rearrange Profiles** — Drag and drop profiles to organize them however you want.
- **Automatic Updates** — The app updates itself in the background, so you don’t have to download anything manually.
- **Logs for Troubleshooting** — If something breaks, the app collects logs to help figure out what’s wrong.
- **One-Click Plugin Updates** — A new button lets you update plugins when an update uses the same URL as the original.
- **A Secret Setting** — We’re not telling you what it does, but if you find it, you’ll know.
