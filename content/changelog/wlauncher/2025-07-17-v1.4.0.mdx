## Bug Fixes

- Fixed a rare case where the app would load as a blank screen under specific conditions.
- Corrected an issue where the UI wouldn’t render properly if the stars aligned just wrong.
- Cleaned up a display bug that only showed up when no one was looking.

## Improvements

- Rebuilt the entire design system from scratch. The default theme now features higher contrast and improved clarity.
- Removed outdated themes that no longer worked with the new system.
- Added 42 brand-new themes to replace the previous 12. Yes, we went a bit overboard.
- Improved overall load times for a snappier launch experience.
- Converted several modules to use dynamic imports, improving performance and reducing startup overhead.

## Notes

- One of the new themes is just slightly off-white—because someone asked for “subtle but bold.”
- The old themes have been respectfully archived in a zip file labeled `do_not_open.zip`.
