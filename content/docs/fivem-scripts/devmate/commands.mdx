## Menu command

Use the command configured by `MenuCommand` to open DevMate. The default is:

```text title="FiveM chat or F8 console"
devmate
```

The player must have the `OpenMenu` permission. Running the command while the menu is already open has no effect.

## FiveM key bindings

DevMate registers two entries under FiveM's key binding settings:

- **DevMate: Open menu** opens the menu.
- **DevMate: Open menu modifier** is an optional modifier for the open-menu binding.

Both bindings are unassigned by default. If only **Open menu** is assigned, that key opens DevMate normally. If the optional modifier is also assigned, the player must hold the modifier while pressing the open-menu key.

Configure these from FiveM's settings rather than `config.jsonc`.

## Closing the menu

These shortcuts are fixed while the DevMate interface has focus:

| Shortcut | Behavior |
| --- | --- |
| `Escape` | Close the menu and leave currently enabled tools running. |
| `Shift` + `Escape` | Disable all active client tools, then close the menu. |

Because the browser interface owns keyboard focus while DevMate is open, these close shortcuts are handled by the interface and are not FiveM key bindings.

## Desktop console commands

DevMate Desktop's Client Logs tool can send commands to the local FiveM client console. This does not grant additional server permissions; FiveM and DevMate still enforce the connected player's normal access.
