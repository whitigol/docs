DevMate reads `DevMate/config.jsonc`. JSONC supports comments and trailing commas, and the bundled schema at `DevMate/schemas/config.schema.json` provides validation and completion in compatible editors.

<Callout type="info">
	Keep `"$schema": "./schemas/config.schema.json"` unchanged. The schema ships inside the resource, so configuration validation does not depend on an external website.
</Callout>

## Default configuration

```jsonc title="DevMate/config.jsonc"
{
	"$schema": "./schemas/config.schema.json",
	"MenuCommand": "devmate",
	"LicenseKey": "License Key Here",
	"SafeRestart": { "warnTime": 5, "lagTime": 2 },
	"Permissions": {
		"enabled": true,
		"groups": [
			{
				"group": "admin",
				"permissions": ["OpenMenu", "EntityViewer", "ResourceManager", "CodeExecuter", "OneSyncBlip", "GameModifier", "CoordsTool", "BoneViewer"],
			},
			{
				"group": "developer",
				"permissions": ["OpenMenu", "EntityViewer", "ResourceManager", "OneSyncBlip", "GameModifier", "CoordsTool", "BoneViewer"],
			},
			{
				"group": "tester",
				"permissions": ["OpenMenu", "EntityViewer", "OneSyncBlip", "CoordsTool", "BoneViewer"],
			},
		],
	},
	"EventWatcher": [{ "eventName": "playerSpawned", "logLevel": "INFO" }],
}
```

## General settings

| Setting | Type | Description |
| --- | --- | --- |
| `$schema` | string | Relative path to the schema bundled with DevMate. |
| `MenuCommand` | string | Command players use to request the menu. Do not include `/`. |
| `LicenseKey` | string | License key from your Big Daddy Scripts account. |

## Safe restart

`SafeRestart` controls the delay used when Resource Manager safely restarts a resource.

| Setting | Type | Description |
| --- | --- | --- |
| `warnTime` | number | Seconds of warning before the restart begins. Must be zero or greater. |
| `lagTime` | number | Additional seconds to wait during the safe restart. Must be zero or greater. |

## Permissions

When `Permissions.enabled` is `true`, DevMate converts each configured entry into FiveM ACE permissions named `devmate.<Permission>`. A player receives a tool when their ACE principal belongs to the corresponding `group.<group>`.

When permission enforcement is disabled, every DevMate permission is granted to connected players. Only disable it on a controlled development server.

| Permission | Allows |
| --- | --- |
| `OpenMenu` | Opening the DevMate interface. |
| `EntityViewer` | Inspecting and interacting with nearby entities. |
| `ResourceManager` | Starting, stopping, and restarting server resources. |
| `CodeExecuter` | Executing Lua or JavaScript on the client or server. |
| `OneSyncBlip` | Showing the OneSync radius visualization. |
| `GameModifier` | Changing pedestrian and vehicle density. |
| `CoordsTool` | Viewing coordinates and measuring distance. |
| `BoneViewer` | Displaying selected vehicle and pedestrian bones. |

<Callout type="error" title="Protect dangerous tools">
	`ResourceManager` and `CodeExecuter` can make server-wide changes. Grant them only to trusted developers. Keep the identifier spelling `CodeExecuter` as shown; it is the permission name expected by DevMate.
</Callout>

## Event watcher

Each `EventWatcher` entry identifies an event to observe and the level used when logging it.

```jsonc
"EventWatcher": [
	{ "eventName": "playerSpawned", "logLevel": "INFO" },
	{ "eventName": "playerDropped", "logLevel": "WARN" },
]
```

Valid levels are `ALL`, `INFO`, `DEBUG`, `WARN`, and `ERROR`. Lowercase equivalents are also accepted. Keep the list focused; watching high-frequency events can produce substantial console output.
