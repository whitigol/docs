DevMate reads `DevMate/config.jsonc`. JSONC supports comments, and the included schema provides validation and suggestions in compatible editors.

<Callout type="info">
  Keep `$schema` set to `./schemas/config.schema.json` and `ConfigVersion` set to `2`.
</Callout>

## Complete example

```jsonc title="DevMate/config.jsonc"
{
  "$schema": "./schemas/config.schema.json",
  "ConfigVersion": 2,
  "MenuCommand": "devmate",
  "LicenseKey": "paste-your-license-key-here",
  "AutomaticUpdates": true,
  "ResourceExplorerEnabled": true,
  "SafeRestart": {
    "warnTime": 5,
    "lagTime": 2,
  },
  "Permissions": {
    "enabled": true,
    "groups": [
      {
        "group": "admin",
        "permissions": [
          "OpenMenu",
          "EntityViewer",
          "ResourceManager",
          "ResourceExplorer",
          "CodeExecuter",
          "EventWatcher",
          "OneSyncBlip",
          "GameModifier",
          "CoordsTool",
          "BoneViewer",
        ],
      },
      {
        "group": "developer",
        "permissions": [
          "OpenMenu",
          "EntityViewer",
          "ResourceManager",
          "ResourceExplorer",
          "EventWatcher",
          "OneSyncBlip",
          "GameModifier",
          "CoordsTool",
          "BoneViewer",
        ],
      },
      {
        "group": "tester",
        "permissions": ["OpenMenu", "EntityViewer", "OneSyncBlip", "CoordsTool", "BoneViewer"],
      },
    ],
  },
}
```

## Settings

| Setting | Description |
| --- | --- |
| `ConfigVersion` | Configuration format version. DevMate v2 requires `2`. |
| `MenuCommand` | Chat and console command used to open the menu, without `/`. |
| `LicenseKey` | Your private DevMate license key. |
| `AutomaticUpdates` | Downloads and verifies newer DevMate resource builds when the server starts. A restart is required to load an installed update. |
| `ResourceExplorerEnabled` | Enables resource scanning and the Resource Explorer module. |
| `SafeRestart.warnTime` | Seconds given to clients to clean up entities before a stop or restart. |
| `SafeRestart.lagTime` | Additional seconds DevMate waits before running the resource command. |
| `Permissions.enabled` | Enforces group permissions when `true`. When `false`, every player receives every DevMate permission. |
| `Permissions.groups` | Maps FiveM ACE groups to DevMate permissions. |

<Callout type="error" title="Do not disable permissions on a public server">
  Setting `Permissions.enabled` to `false` gives every connected player access to Code Executor, Resource Explorer, and all other DevMate tools.
</Callout>

## Permissions

Each configured group grants ACE permissions in the form `devmate.PermissionName`. Assign players to matching FiveM groups with your existing permission setup or with `add_principal`.

| Permission | Grants access to | Risk |
| --- | --- | --- |
| `OpenMenu` | Open the in-game DevMate interface | Required |
| `EntityViewer` | Inspect nearby entities and use free-aim entity actions | Medium |
| `ResourceManager` | Start, stop, and safely restart resources | High |
| `ResourceExplorer` | Read and overwrite text files in server resources | Critical |
| `CodeExecuter` | Execute Lua or JavaScript on the client or server | Critical |
| `EventWatcher` | Subscribe to client or server events and view payloads | High |
| `OneSyncBlip` | Display the local OneSync radius | Low |
| `GameModifier` | Change local pedestrian and traffic density | Low |
| `CoordsTool` | View and copy coordinates and measure distance | Low |
| `BoneViewer` | Display selected vehicle and pedestrian bones | Low |

<Callout type="warning" title="Permission name spelling">
  `CodeExecuter` is the permission identifier used by DevMate. Keep this exact spelling in `config.jsonc`.
</Callout>

### Example group assignment

```ini title="server.cfg"
add_principal identifier.license:YOUR_LICENSE_IDENTIFIER group.developer
```

Group names are case-sensitive. Restart DevMate after changing `config.jsonc`, and reconnect players after changing their principal assignments.

## Resource Explorer access

Resource Explorer generates filesystem permissions in `DevMate/permissions/resources.cfg`. Do not edit that file; DevMate rewrites it as resources are discovered.

Newly discovered resources appear as **pending** until the next full server restart. This is required because FiveM applies the generated filesystem permissions from `server.cfg` during startup.

Set `ResourceExplorerEnabled` to `false` if you do not need file access. Resource Manager continues to work independently.
