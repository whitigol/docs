## Public API status

DevMate 2.0 beta does not currently expose a supported public FiveM exports API.

The events and messages used by the in-game interface and DevMate Desktop are internal implementation details. Do not call them from another resource; they may change between beta releases without compatibility guarantees.

<Callout type="info">
	A documented export will appear here when it becomes part of DevMate's supported public API. Until then, use the in-game menu, the configured command, and DevMate Desktop.
</Callout>

If you have an integration use case, share it in the [Whitigol Software Discord](https://discord.gg/NuPCpBa4Vy).
