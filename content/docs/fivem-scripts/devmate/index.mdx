DevMate v2 brings server management, live debugging, and everyday development tools into one interface. Use it in game or connect the optional Windows Desktop app for a larger workspace and live client logs.

<Callout type="warning" title="Development servers only">
  DevMate can run code, edit resource files, and control server resources. Use it on a private development server and grant access only to people you trust.
</Callout>

## What you can do

- Inspect entities, vehicle bones, pedestrian bones, coordinates, and OneSync range.
- Start, stop, and safely restart resources.
- Browse and edit text files inside server resources.
- Run Lua or JavaScript on the client or server.
- Watch client and server events and inspect their payloads.
- Adjust pedestrian and traffic density while testing.
- Use the same authorized tools from DevMate Desktop.

## Opening DevMate

Run the configured menu command in chat. The default is:

```text
/devmate
```

You can also assign **DevMate: Open menu** and the optional **DevMate: Open menu modifier** in FiveM's key binding settings. Both bindings are unassigned by default. If you bind a modifier, you must hold it while pressing the menu key.

- Press **Escape** to close the menu.
- Press **Shift+Escape** to close the menu and turn off all active client tools.
