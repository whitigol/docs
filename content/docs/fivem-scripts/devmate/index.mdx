## DevMate 2.0

DevMate is an in-game development toolkit for FiveM. Version 2.0 introduces a redesigned interface, a permission-aware tool suite, optional keyboard shortcuts, and an optional Windows desktop companion.

DevMate is co-created by [Whitigol](https://github.com/whitigol) and [TheLaw](https://github.com/xXxTHELAWxXx97), and distributed by [Big Daddy Scripts](https://bigdaddyscripts.com).

<Callout type="warning" title="Beta release">
	DevMate 2.0 is currently in beta. Review the release notes and test it on a development server before deploying it to a production environment.
</Callout>

<Callout type="error" title="Security warning" icon={<Lucide.ShieldAlert className="size-6 text-red-500" />}>
	Resource management and code execution can affect your entire server. Grant DevMate permissions only to trusted developers and administrators.
</Callout>

## Included tools

- **Entity Viewer** inspects aimed entities and displays nearby objects, vehicles, and pedestrians.
- **Resource Manager** lists resources and can start, stop, or safely restart them.
- **Code Executor** runs Lua or JavaScript in the selected client or server context.
- **OneSync Blip** visualizes the approximate OneSync synchronization area.
- **Game Modifier** adjusts pedestrian and vehicle population density.
- **Coordinates Tool** displays position, heading, ground height, and distance from a saved origin.
- **Bone Viewer** displays selected vehicle and pedestrian bones.
- **Client Logs** displays live FiveM client output when DevMate Desktop is running.

Most tools are available in the in-game menu. DevMate Desktop mirrors the same live session in a full Windows application and adds client log viewing and console commands.
