title: Installation
description: Install DevMate 2.0, activate its license, and enable resource-management commands.

<Callout type="warning" title="Prerequisite">
	This guide assumes you have purchased DevMate from [Big Daddy Scripts](https://bigdaddyscripts.com/Products/View/2586/DevMate).
</Callout>

## 1. Download and extract DevMate

Download the latest DevMate package from your [Big Daddy Scripts account](https://bigdaddyscripts.com/Account). Extract the `DevMate` folder into your server's resources directory.

<Callout type="warning" title="Keep the resource name">
	The folder must remain named `DevMate`. Renaming it breaks the bundled resource principal and prevents DevMate from starting correctly.
</Callout>

## 2. Add DevMate to `server.cfg`

Add both lines below. The permissions file grants the DevMate resource permission to execute the server commands used by Resource Manager.

```text title="server.cfg"
exec @DevMate/permissions.cfg
ensure DevMate
```

Place the `exec` line before `ensure DevMate`.

## 3. Add your license key

Copy your license key from the Licenses section of your [Big Daddy Scripts account](https://bigdaddyscripts.com/Account), then replace the placeholder in `DevMate/config.jsonc`.

```jsonc title="DevMate/config.jsonc"
{
	"$schema": "./schemas/config.schema.json",
	"MenuCommand": "devmate",
	"LicenseKey": "your-license-key-here",
	// Keep the remaining default configuration here.
}
```

Keep the key private. Do not place it in a public repository, screenshot, or support message.

## 4. Assign access groups

DevMate's default configuration defines `admin`, `developer`, and `tester` permission groups. Assign a player's existing ACE principal to the appropriate group in `server.cfg`.

```text title="server.cfg"
add_principal identifier.license:YOUR_PLAYER_LICENSE group.developer
```

You may use any group names in `config.jsonc`, provided the same `group.<name>` principal is assigned through your server's ACE configuration. See [Configuration](/docs/fivem-scripts/devmate/config) for every permission.

## 5. Start and verify

Start the server and review the server console. A successful startup ends with the DevMate license and diagnostics report. Join the server and enter the configured menu command—`/devmate` by default.

If the menu does not open, verify that:

- the resource folder is named `DevMate`;
- the license key is valid;
- the player has `devmate.OpenMenu` through one of the configured groups; and
- `exec @DevMate/permissions.cfg` appears before `ensure DevMate` in `server.cfg`.

DevMate Desktop is optional. Install it only if you want the standalone interface and live client-console tools described in [DevMate Desktop](/docs/fivem-scripts/devmate/desktop).
